# Golf Classic

A cartoon mobile golf game that runs in the browser and installs to your phone's home screen.

Play: https://lester-dotcom.github.io/golf-classic/

To install on iPhone: open the link in Safari, tap Share, then "Add to Home Screen".
On Android: open in Chrome and tap "Install app" (or menu > Add to Home screen).

Courses: Parkland, Desert Dunes, Lakeland Links, Scottish Links, Alpine.
